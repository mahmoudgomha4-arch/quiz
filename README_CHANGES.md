# ملخص التعديلات

## ملفات جديدة
- `css/features.css` — تنسيق كل الميزات الجديدة (متجاوب + وضع داكن).
- `js/certificates.js` — نظام الشهادات (40 تصميم).
- `js/user-notifications.js` + `sw.js` — إشعارات الويب للطلاب.

## ملفات معدّلة (إضافات فقط، بدون حذف ميزة)
`index.html`, `main.js` (باقي الملفات لم تتغير). الدوال القديمة كلها لسه موجودة.

## الميزات
1. **الشهادات**: 40 تصميم، معاينة واختيار من تبويب «🎓 الشهادات». الشهادة تُحفظ كـ snapshot وقت الإصدار، فتغيير التصميم لاحقًا لا يمس القديم (إعادة الإصدار اختيارية وصريحة). تصميم افتراضي + تصميم خاص لكل امتحان، عربي/English/ثنائي، PDF وصورة.
2. **إشعارات الأدمن**: جرس + نقطة حمراء + عدّاد لحظي. حالة القراءة لكل أدمن منفصلة (`adminReads/{adminId}`).
3. **الشكاوى**: إشعار فوري، تُقرأ لمن فتحها فقط.
4. **المنتدى**: ✓ أُرسلت / ✓✓ وصلت / ✓✓ أزرق قرأها أدمن — مخزّنة في الداتابيز (`deliveredTo` / `readBy`).
5. **التصحيح المقالي**: Pending → Under Review → Corrected → Reviewed، مع اسم المصحّح والمراجِع والوقت، وتبويب «✍️ التصحيح المقالي» لكل الامتحانات، وحفظ مسودة.
6. **إشعارات الطلاب**: اشتراك اختياري، لا يُطلب الإذن إلا بضغطة صريحة، الرفض/«مش دلوقتي» يُحترم، والإشعار يفتح الامتحان.
7. **جلسة الأدمن**: token عشوائي (يُحفظ منه hash فقط في الداتابيز، وكلمة السر لا تُحفظ نهائيًا). زر «تسجيل الخروج» يلغي الجلسة. تغيير كلمة السر/تعطيل/حذف الحساب يلغي جلساته.
8. **الطالب**: الاسم والأكواد تفضل محفوظة على الجهاز، بحث بالكود + اختيار الامتحان، وتسجيل خروج.
9. **دخول الأدمن**: زر لوحة التحكم يظهر فقط لمن يكتب اسمه مطابقًا لاسم أدمن، وبجانبه شارة «أدمن». الدخول بلا كلمة سر لو عنده جلسة صالحة وكتب اسمه؛ وإلا يُطلب الاسم + كلمة السر.

## مسارات Firebase الجديدة (لازم تسمح بها قواعد الداتابيز)
`adminSessions`, `adminReads`, `adminNotifications`, `essayQueue`, `essayQueueMeta`, `publicEvents`, `certSettings`, `certificates`، وحقول جديدة داخل `adminForum/messages/*` و`examResults/*` و`exams/*`.

## ⚠️ ملاحظات أمان مهمة
المنصة تعتمد على Firebase Realtime Database من المتصفح مباشرة بدون Firebase Authentication، فالقواعد هي خط الدفاع الحقيقي. إخفاء زر الأدمن واشتراط الاسم **راحة استخدام وليست حماية**. للحماية الفعلية انقل التحقق إلى Firebase Auth + Rules (أو Cloud Functions). لو قواعدك الحالية `.read/.write: true` فكل شيء يعمل لكن البيانات (ومنها hashes كلمات السر الموجودة أصلًا) قابلة للقراءة من أي شخص.

## ملاحظات
- `resetAllResults` في الكود الأصلي يستخدم `ADMIN_PASS` غير معرّف (خطأ قديم) — لم ألمسه لأنه خارج الطلب.
- نتيجة الطالب بالكود تُعرض فقط لو خيار «إظهار النتيجة للطلاب» مفعّل في الامتحان (سلوك أصلي محفوظ).
- الشهادة تظهر للناجح بعد ظهور الدرجة (بعد انتهاء تصحيح المقالي).
